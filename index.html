📄 Guia Completo de Instalação

Aprenda a instalar qualquer mod da VCORE GAMES usando o Mod Manager

📋 O que você precisa ter:
⚠️ É obrigatório criar uma conta gratuita no Nexus Mods para poder baixar os programas abaixo:
• GRB Mod Manager instalado - Baixar aqui
• AnvilToolkit instalado - Baixar aqui
• Arquivo do mod baixado (.zip/.rar/.7z)
• Jogo Ghost Recon Breakpoint instalado

✅ PASSO 1 — Configurando o Programa
1. Abra o GRB Mod Manager
2. Clique em 📁 Selecionar Pasta do Jogo e escolha a pasta onde o jogo está instalado no seu PC
3. Clique no ícone de 🔨 Ferramentas e selecione o arquivo AnvilToolkit.exe que você já instalou

✅ PASSO 2 — Adicionando e Instalando o Mod
1. Clique em ➕ Adicionar Mod
2. Selecione o arquivo do mod que você baixou (não precisa descompactar!)
3. O programa vai ler automaticamente. Clique em ✅ Instalar e aguarde terminar
4. No final, anote os nomes dos arquivos .forge que aparecerem na mensagem

✅ PASSO 3 — Etapa Obrigatória: Empacotar
⚠️ Sem essa etapa o mod não funciona!
1. Clique em 🛠️ Abrir AnvilToolkit
2. Selecione um por um os arquivos .forge que foram indicados
3. Clique em 🔄 Repacotar / Repack e confirme
4. Aguarde concluir e feche o programa

✅ PASSO 4 — Pronto!
Volte para a tela principal, veja que o mod está como ATIVADO. Agora é só abrir o jogo normalmente pelo Ubisoft Connect ou Steam que tudo já estará aplicado! 🎮

❌ Como desinstalar (voltar ao original)
1. Abra o Mod Manager
2. Na lista, clique no mod e escolha 🗑️ Remover / Desinstalar
3. Repita o PASSO 3 para restaurar os arquivos originais

💡 Dica: Instale apenas um mod por vez para evitar conflitos ou erros.
