📄 Guia Completo de Instalação

Aprenda a instalar qualquer mod da VCORE GAMES

🚀 Comprou um Pacote? É só copiar e jogar!

Os Pacotes já vêm pré-configurados. Siga o Passo 0 e ignore os demais.

📂 Passo 0 — Como usar o arquivo pronto

1. Baixe e descompacte o arquivo recebido (.zip ou .rar)

2. Navegue até a pasta raiz do jogo — onde fica o GRB.exe

📁 Onde costuma estar:

• Ubisoft Connect: C:\Program Files (x86)\Ubisoft\Ubisoft Game Launcher\games\Ghost Recon Breakpoint

• Steam: C:\Program Files (x86)\Steam\steamapps\common\Ghost Recon Breakpoint

3. Copie os arquivos para dentro dessa pasta

4. Abra o jogo — os mods já estarão ativos! 🎮

🚨 AO INSTALAR OS ARQUIVOS, INICIE UM SAVE NOVO!

É OBRIGATÓRIO começar um save novo após a instalação para evitar bugs e conflitos nos arquivos do jogo.

👇 Passos abaixo: somente para mods individuais

📋 O que você precisa ter:
⚠️ Conta gratuita no Nexus Mods obrigatória
• GRB Mod Manager - Baixar aqui
• AnvilToolkit - Baixar aqui

✅ PASSO 1 — Configurando
Abra o GRB Mod Manager, selecione a pasta do jogo e configure o AnvilToolkit.

✅ PASSO 2 — Instalando
Adicione o arquivo do mod (sem descompactar) e clique em Instalar.

✅ PASSO 3 — Empacotar (obrigatório!)
⚠️ Abra o AnvilToolkit, selecione os arquivos .forge e clique em Repack.

✅ PASSO 4 — Pronto!
Abra o jogo normalmente e tudo estará aplicado! 🎮
